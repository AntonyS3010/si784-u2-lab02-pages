Primes.Lib - Pruebas unitarias con xUnit

PrimeService.IsPrime indica si un entero es primo. Devuelve false para valores menores que dos y para números compuestos.

var service = new Primes.Lib.PrimeService();
service.IsPrime(19); // true
service.IsPrime(20); // false

Las pruebas utilizan [Fact], [Theory] e [InlineData]. Se comprueba cada entero del 2 al 20: los primos esperados son 2, 3, 5, 7, 11, 13, 17 y 19. También se comprueban -1, 0, 1 y los límites de Int32.

El algoritmo prueba divisores hasta la raíz cuadrada mediante una comparación que evita multiplicaciones que puedan desbordar.

El reporte de cobertura se encuentra enlazado desde la portada del sitio.
